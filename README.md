This dependency-free Node.js parser recovers rows and reports errors in malformed CSV. It reads the challenge’s `cases.json` and writes one result per case to `answers.json`.

## Run it

With Node.js 22.6 or later and the input and output directories already created, run the following command in PowerShell.

```powershell
$env:MAKEFUN_INPUT_DIR = 'input'
$env:MAKEFUN_OUTPUT_DIR = 'output'
node --experimental-strip-types main.ts
```
